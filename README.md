🚗 Road Accident Severity Prediction
Predicts road accident severity (Slight, Serious, or Fatal) using factors like weather, road condition, lighting, vehicle type, and number of casualties. The project cleans the data, stores it in a database, analyzes it with SQL and Python, visualizes patterns through charts, and trains a machine learning model to predict the severity of new accidents.

📌 Features
Data Cleaning – Handles missing values and duplicate records
SQLite Database – Stores accident data for structured querying
SQL Analysis – Runs queries to get quick insights (total accidents, severity counts, etc.)
Python Analysis – Explores data using Pandas (distributions, percentages, etc.)
Visualizations – Generates charts using Matplotlib and Seaborn
Machine Learning – Trains Decision Tree and Random Forest models to classify severity
Prediction – Predicts the severity of a new accident based on input conditions
🛠️ Tech Stack
Language: Python
Libraries: Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Joblib
Database: SQLite
Environment: Jupyter Notebook
📂 Project Structure
├── Road_Accident_Severity_Prediction.ipynb   # Main notebook
├── road_accident.db                          # SQLite database (generated)
├── road_accident_model.pkl                   # Saved ML model (generated)
├── graphs/                                   # Generated visualizations
└── README.md
⚙️ How It Works
Load Data – Reads the accident dataset from a CSV file
Clean Data – Fills missing values and removes duplicates
Store in Database – Saves cleaned data into a SQLite database
SQL Analysis – Runs SQL queries for quick statistics
Python Analysis – Explores severity distribution and other patterns
Visualize – Creates charts to show accident trends
Train Model – Trains ML models (Decision Tree, Random Forest) on features like weather, road surface, lighting, vehicle type, number of vehicles, and casualties
Predict – Takes new accident details and predicts the likely severity

Given new accident conditions (e.g., weather, road surface, lighting, number of vehicles, and casualties), the trained model predicts whether the accident is likely to be Slight, Serious, or Fatal — helping with road safety analysis and risk assessment.
